# 共聴系統図エディタ

テレビ共同受信設備(共聴)の系統図を描き、テレビ端子までの信号レベルを自動計算するブラウザアプリです。
ビルド不要で、`index.html` をブラウザで開けば動きます。

**公開版: https://holtsiwata-sketch.github.io/kyocho-zumen/**

作った図面は、使っているブラウザの中にだけ自動保存されます。他の人へ渡すときや別の PC で開くときは、「保存」で JSON ファイルに書き出し、相手は「開く」で読み込んでください。

## 起動

```bash
python -m http.server 8765 --directory kyocho_zumen
```

起動後、http://localhost:8765 を開きます。`index.html` を直接ダブルクリックして開いても動きます。

## できること

- **作図**: 国交省「公共建築設備工事標準図」(JIS C 0303 準拠)の図記号で部品を配置します。対象はアンテナ、ブースタ、混合器、分岐器(1/2/4)、分配器(2/4/6/8)、テレビ端子(1/2端子)、直列ユニット、終端抵抗器、機器収容箱です。
- **配線**: 部品にマウスを乗せると端子が表示されます。橙の出力端子から緑の入力端子へドラッグして配線します。
- **階レーン**: RF・5F…1F のように階ごとの帯を表示します。階の名前と高さは図面設定で変えられます。
- **番号付け**: 機器とケーブルに、上流から順に ①②… を自動で振ります。
- **レベル計算**: 7つの周波数(地デジ 470/710MHz、BS・110°CS 1000〜3224MHz)ごとに計算します。
  - ケーブル損失: 種類(5C/7C)と長さから計算
  - 分配損失、分岐器の挿入損失と結合損失、端子損失
  - ブースタ: 入力ATT、入力チルト、利得、利得調整
- **C/N 計算**(JEITA 3-8 の方式): アンテナ出力の C/N、ブースタ単体の C/N(入力レベル − 熱雑音 − NF)、受像機単体の C/N を電力加算して総合 C/N を求めます。
  - 熱雑音: 地デジ 2.3 dB / BS・110°CS(2K) 9.4 dB / 4K8K 10.1 dB
  - 所要 C/N: 地デジ 24 dB / 衛星 2K 17 dB / 4K8K 18 dB
  - 図面設定で、衛星の種別(2K/4K8K)、受像機を含めて判定するか、受像機の NF、端子から受像機までのケーブル長と分波器の損失を設定できます。
  - アンテナ出力の C/N は、各アンテナの設定に現地の測定値を入れてください(初期値は JEITA 計算例の値: UHF 32.2 dB / BS・CS 19.0 dB)。
- **チェック**: 次の項目を自動で検出し、図面上の色と右パネルの一覧で示します。
  - 端子レベルの範囲外(地デジ 50〜81 / BS・CS 54〜81 dBμV)
  - 未接続の出力(終端抵抗器が必要)
  - ブースタ出力の定格超過
  - C/N 不足
- **レベル計算表**: テレビ端子を選ぶと、アンテナからその端子までの計算過程を JEITA 形式の表で表示します。
- **端子一覧**: 全端子のレベルと適合/範囲外の判定を一覧にします。
- **スマホ対応**: 画面幅 760px 以下(または高さ 520px 以下)では、図面を全画面で表示します。
  - 下部のタブで「部品 / 詳細 / 計算表 / チェック」を開きます。
  - 2 本指で拡大縮小・移動します。
  - 部品やケーブルをタップすると、図面の上部に操作バー(削除・複製・詳細・選択解除)が出ます。
  - 配線は、部品をタップして大きく表示された橙の端子をタップし、次に接続先をタップします。
  - 新規・保存・出力などは ☰ メニューにあります。
- **出力**: SVG、PNG、印刷(A3横、端子一覧つき)、JSON での保存と読み込みに対応しています。作業中の図面はブラウザに自動保存されます。

## 計算の検証

ツールバーのサンプルは、JEITA「受信システム計算事例集 第2.2a版」の計算例を再現したものです。

- **例:ビル**(3-7 ビル共同受信 5階新設): テレビ端子出力が 7 周波数すべてで JEITA の値と一致します(69.5 / 68.8 / 66.5 / 68.7 / 65.9 / 63.3 / 59.8 dBμV)。
- **例:戸建**(3-8 ホーム共同受信の C/N 計算例): 総合 C/N が JEITA の値と一致します(地デジ 31.1 dB / BS・CS 18.8 dB)。ブースタ単体 C/N、受像機入力レベル、受像機単体 C/N も一致します。

- ブラウザで確認する場合: `test/verify.html` を開く
- Node で確認する場合: `node test/verify.js`

JEITA の手計算表と合わせるため、各段のケーブル損失やブースタ利得は 0.1 dB 単位に丸めてから合算しています。

## 損失データについて

分配器・分岐器・端子などの損失の初期値は、JEITA 計算事例集の値か、一般的な製品の目安値です。どちらに当たるかは「図記号・損失データ」タブに出典として表示しています。実際の設計では、部品ごとの「上書き」欄に製品カタログの値を 7 つ(470/710/1000/1489/2150/2681/3224MHz の順)入力してください。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html`, `style.css` | 画面 |
| `js/lib.js` | 図記号、損失テーブル、レベル計算エンジン(UI に依存しない) |
| `js/app.js` | 作図 UI、プロパティ、表、出力 |
| `js/sample.js` | JEITA 計算例のサンプル図面 |
| `test/` | 計算エンジンの照合テスト |
| `RESEARCH.md` | 図記号・書き方・計算方法の調査ノート |
